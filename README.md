# うさチルplayer

広告なしで、スマホに入っている自分の曲を聴ける音楽プレイヤーです。
ジャケット連動の背景、音に合わせて動くエフェクト、プレイリスト、イコライザー、歌詞表示に対応しています。

公開ページ: https://bluewhale80t-cmyk.github.io/jibun-player/
